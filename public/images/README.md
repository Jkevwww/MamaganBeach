# Image Assets Folder

Place your local images, backgrounds, and logos here.

## Folder Structure

```
public/
├── images/
│   ├── logos/           # Resort logos, brand marks
│   ├── backgrounds/     # Hero backgrounds, section backgrounds
│   ├── facilities/      # Facility photos (cabanas, jet skis, etc.)
│   ├── icons/           # Custom icons
│   └── uploads/         # User/admin uploaded images
```
